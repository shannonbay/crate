# Crate

A music player for Windows built around albums and artists: edit tags in bulk, write notes, set custom covers, add band members, and skin it your way.

**Website:** https://shannonbay.github.io/crate/

**Download:** get the installer from the [latest release](https://github.com/shannonbay/crate/releases/latest) (the file ending in `_x64-setup.exe`). It isn't code-signed yet, so Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.

Found a problem or have an idea? [Open an issue](https://github.com/shannonbay/crate/issues).

This repository holds Crate's website (published with GitHub Pages) and its releases.

Album art and artist images in the screenshots are public-domain paintings from Wikimedia Commons, credited on the website.
